# 학생회 투표

전교 학생회장·부회장 선거를 교실 컴퓨터 한 대로 진행하는 웹 프로그램입니다.
학생은 키보드 대신 화면의 후보 번호 칸을 마우스로 눌러 투표합니다.

사이트: https://winter-choi.github.io/student-vote/

## 쓰는 법

1. 선거 이름, 항목(전교회장, 전교부회장)과 후보를 적습니다. 후보는 한 줄에 한 명, 기호 순서대로 적습니다.
2. 투표자 수, 다음 투표까지 기다리는 시간(1~9초), 관리자 비밀번호를 정합니다.
3. 확인 화면에서 내용을 보고 시작합니다. 전체 화면을 켜 두면 좋습니다.
4. 학생이 한 명씩 나와서 번호 칸을 누르고, 이름을 확인한 뒤 투표하기를 누릅니다.
5. 투표자 수가 다 차면 저절로 끝납니다. 결과 보기를 누르고 비밀번호를 넣으면 개표가 시작됩니다.

## 알아 둘 점

- 표는 투표한 컴퓨터의 브라우저(localStorage)에만 저장되고, 어디로도 전송되지 않습니다.
  시작부터 개표까지 같은 컴퓨터, 같은 브라우저로 진행하세요.
- 시크릿 창에서는 창을 닫으면 표가 사라집니다.
- 창을 닫거나 새로고침해도 같은 브라우저로 다시 열면 이어서 할 수 있습니다.
- 인터넷이 안 되는 컴퓨터에서는 `index.html` 파일을 내려받아 크롬이나 엣지로 열면 됩니다.

## 파일

- `index.html`: 프로그램 전체(HTML, CSS, JavaScript 한 파일)
